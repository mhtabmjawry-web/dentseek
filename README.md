# DentPath — مسیر حرفه‌ای دندانپزشکی

وب‌اپ فارسی و راست‌چین برای ساختن یک مسیر یادگیری مستقل و قابل پیگیری در دوران تحصیل دندانپزشکی.

## امکانات

- داشبورد پیشرفت و نقشه‌راه هفت‌مرحله‌ای از علوم پایه تا یادگیری مادام‌العمر
- ۴۹ مبحث آموزشی با هدف، محورهای یادگیری، تمرین و معیار ارزیابی
- کتابخانه منابع رسمی و منتخب با نوع دسترسی، زبان و کاربرد هر منبع
- برنامه هفتگی پیشنهادی ۸ ساعته، قابل تیک زدن
- دفتر مهارت‌ها با تفکیک مشاهده، تمرین شبیه‌سازی، اجرای تحت نظارت و تأیید استاد
- دفتر کیس‌های آموزشی با قالب ساختاریافته و تأکید بر حذف داده‌های شناسایی‌کننده
- سازنده سؤال PICO و چک‌لیست نقد مقاله
- چک‌لیست آموزشی ایمنی و حرفه‌ای‌گری
- کتابخانه کتاب‌های مرجع
- حالت روشن/تیره، خروجی پشتیبان و بازیابی JSON
- بدون وابستگی نرم‌افزاری، بدون نیاز به سرور و قابل استفاده در موبایل

## اجرای محلی

فقط فایل index.html را در مرورگر باز کن. برای اجرای از یک سرور محلی می‌توانی از هر static file server دلخواه استفاده کنی.

## انتشار در GitHub Pages

۱. در مخزن به مسیر Settings → Pages برو.
۲. در Build and deployment → Source گزینه GitHub Actions را انتخاب کن.
۳. مطمئن شو Actions برای مخزن مجاز است.
۴. فایل .github/workflows/deploy-pages.yml با هر push به شاخه main اجرا می‌شود و سایت را منتشر می‌کند.
۵. پس از موفقیت workflow نشانی سایت از این الگو پیروی می‌کند:

https://mhtabmjawry-web.github.io/dentseek/

مخزن باید عمومی باشد یا طرح GitHub شما Pages را برای مخزن خصوصی پشتیبانی کند.

## حریم خصوصی و ذخیره داده

- پیشرفت‌ها، وضعیت مهارت‌ها، پروفایل و کیس‌های واردشده فقط در localStorage همان مرورگر ذخیره می‌شوند.
- داده‌ها به سرور یا حساب کاربری ارسال نمی‌شوند.
- با پاک کردن داده‌های مرورگر ممکن است اطلاعات از بین بروند؛ از دکمه خروجی پشتیبان فایل JSON بگیر.
- در دفتر کیس‌ها هیچ نام، شماره پرونده، تاریخ تولد، شماره تماس، عکس قابل‌شناسایی یا داده محرمانه وارد نکن.
- داده‌های پشتیبان شامل اطلاعاتی است که خودت در اپ ثبت کرده‌ای؛ در نگهداری و اشتراک‌گذاری آن احتیاط کن.

## منابع منتخب

لینک‌های داخل اپ به منابع رسمی یا ناشر/انجمن مربوط هدایت می‌شوند، از جمله:

- University of Michigan BlueLink Anatomy
- ADA Clinical Practice Guidelines & Evidence
- AAE Endodontic Clinical Resources
- EFP Clinical Practice Guidelines
- SDCEP Clinical Guidance و راهنمای مشکلات حاد دندانی (نسخه دوم، مارس ۲۰۲۶)
- IADT Dental Trauma Guidelines (راهنمای ۲۰۲۰؛ شامل دسترسی به نسخه فارسی)
- AAPD Reference Manual 2026–27
- CDC Dental Infection Prevention Training
- Colgate Oral Health Network و DT Study Club
- PubMed، PubMed Central، Cochrane Library، ADEA، WHO، NIDCR و FDI

منابع با دسترسی ترکیبی یا نیازمند ثبت‌نام در اپ مشخص شده‌اند. کتاب‌های مرجع تجاری‌اند و باید از نسخه قانونی یا کتابخانه تهیه شوند.

## مسئولیت و محدودیت آموزشی

DentPath یک ابزار برنامه‌ریزی و یادگیری است؛ جایگزین آموزش رسمی دانشکده، گایدلاین‌های به‌روز، مقررات کشور محل فعالیت، آموزش حضوری، تجهیزات استاندارد یا نظارت استاد نیست. تکمیل یک مبحث، تماشای ویدئو یا علامت‌گذاری یک مهارت به معنی صلاحیت مستقل درمان نیست. اقدامات بالینی فقط در حدود صلاحیت و با نظارت موردنیاز انجام شوند. موارد پیچیده، اورژانسی یا خارج از سطح دانشجو باید به استاد یا متخصص ارجاع شوند.

منابع و لینک‌ها ممکن است در طول زمان تغییر کنند؛ پیش از استفاده بالینی، تاریخ و نسخه جاری راهنما را از مرجع اصلی بررسی کن.
